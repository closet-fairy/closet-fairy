# 한 줄에 정규식 하나. #으로 시작하는 줄과 빈 줄은 무시한다.
# 줄 끝에 붙인 # 주석은 정규식 일부로 읽히므로 주석은 반드시 별도 줄에 쓴다.
# 원문에 대소문자 구분 없이 적용한다.
# "다시발랄하게"가 걸리지 않게 원문에서 앞이 한글·숫자가 아닐 때만 막는다.
# 띄어 쓴 "시 발"("외출 시 발 편한")은 의도 파싱에 맡긴다.
# 뒤에 붙는 글자는 始發 계열 단어만 예외로 둔다. 새 예외 단어가 생기면 (?!...) 안에 추가한다.
# "7시발 열차"처럼 시각 뒤의 "시발"(출발)이 걸리지 않게 앞이 숫자일 때도 막지 않는다.
(?<![가-힣0-9])시(발|빨|팔)(?!점|역|지|차)
# 정규화하면 숫자가 지워져 "5개년"과 구분이 안 되므로 원문에서 숫자·한자 수 뒤가 아닐 때만 막는다
(?<![0-9일이삼사오육칠팔구십몇])개년
